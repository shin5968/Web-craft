iPad 등에서 Minecraft Java 에디션의 브라우저 이식 가능성을 확인하는 환경 진단과 일부 Java 코드 실행 실험입니다. HTTPS로 접속해 주세요. 전체 게임 실행은 아직 구현하지 않았습니다.

Java 실행 검사는 빌드 artifact 전체를 배포한 페이지에서 사용할 수 있습니다.

원본 FastBufferedInputStream 클래스의 버퍼 입출력만 검사합니다. 게임 시작·월드 렌더링 검사는 아닙니다.

원본 SimpleBitStorage에 합성 블록 인덱스를 넣어 읽기·쓰기·복사·64비트 압축을 검사합니다. 실제 월드 로딩은 아닙니다.

실제 월드 파일에서 섹션 읽기

Java 에디션 월드의 region 폴더 안 .mca 또는 단일 청크 .nbt 파일을 고르세요. 브라우저 안에서 읽으며 업로드하지 않습니다. 한 번에 섹션 하나만 표시합니다. 원본 NBT 읽기는 직접 작성한 코드이며 블록 데이터 디코딩에는 원본 SimpleBitStorage를 사용합니다.

보고서에는 파일명·크기·가능한 경우 SHA-256, 청크 좌표·DataVersion, 섹션별 결과·블록 상태 요약·오류가 포함됩니다. 원본 파일 내용 전체나 엔티티 데이터는 포함하지 않습니다.

원본 파일은 수정하지 않습니다. 편집은 메모리에만 적용됩니다. LZ4·외부 .mcc 청크·구형 BlockStates 데이터는 아직 지원하지 않습니다.
